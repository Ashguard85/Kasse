# Bon-Schrift – Version 2.1.2

- Artikelpositionen werden im Bilddruck nicht mehr automatisch verkleinert.
- Lange Artikelnamen werden auf mehrere Zeilen umgebrochen.
- Mengen-/Einzelpreiszeilen und Artikelpositionen verwenden dieselbe Schriftgröße.
- Der Zeilenabstand wurde für bessere Lesbarkeit leicht erhöht.
