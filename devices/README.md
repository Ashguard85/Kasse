# KinderKasse Zusatzgeräte – Docker 2.8.0

## NFC-Box
`nfc-box/` – BLE-Gerät `KasseNFC`.

## ESP32-S3 Kundendisplay
`KinderKasse-DisplayBox-ESP32-S3-v1.2.0.zip`

- Docker: WLAN/Cloudflare
- lokale APK: BLE `KasseDisplay`
- Zahlungs-PIN
- Kundenkonto/Self-Service
- Guthabenanzeige
- PIN aktivieren/ändern/deaktivieren

## ESP32-C3 Kassenschublade
`KinderKasse-Drawer-ESP32-C3-v1.0.0.zip`

- Docker: WLAN/Cloudflare
- lokale APK: BLE `KasseDrawer`
- optional nach erfolgreicher Barzahlung

Alle Zusatzgeräte sind optional und nutzen voneinander getrennte Services.
